# 코인 나이트 광고

게임이 읽는 광고 파일: `ads.json` → https://darkclxk-bania.github.io/advertisement/ads.json

- `rotateSec`: 광고가 바뀌는 간격(초, 최소 3)
- `ads`: 광고 목록. 각 항목 `title`(제목) · `text`(한 줄) · `url`(누르면 열 주소, 없으면 "") · `bg`(바탕색) · `fg`(글씨색)
- 이 파일만 고쳐서 올리면 앱 업데이트 없이 몇 분 안에 바뀜 (게임은 못 읽으면 앱 안 기본 광고를 씀)
- 공개 저장소: 광고 문구 · 링크만 둘 것
